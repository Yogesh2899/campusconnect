# Week 6 - Software Requirements Specification

## Problem

Connect the SRS to functional and security verification.

## Relevant Context

The SRS consolidated the functional requirements, interfaces, feasibility findings and quality targets.

## Key Observation

The SRS describes both intended behavior and quality targets. I wrote expected behaviors for verification and kept performance and reliability targets for later measurement.

## Solution

I contributed to the SRS purpose, scope and functional requirements. I reviewed FR-01 for authentication, FR-04 for booking conflicts and FR-05 for approval permissions. I recorded the proposed security requirements for bcrypt password hashing, JWT session validation and role-based authorization. The SRS provided requirement references for testing and security review.

## Next Steps

Turn the requirements into test conditions and expected results.
