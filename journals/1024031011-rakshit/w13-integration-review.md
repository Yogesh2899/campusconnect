# Week 13 - Integration review

## Problem

The integrated app needed to keep its interface and stored appointment records consistent.

## Relevant Context

The completed application combined the frontend views, persistent appointment records and meeting updates.

## Key Observation

Availability and request states can change while a user is viewing them. I used the server response to update the on-screen state after submission.

## Solution

I connected booking and request screens to backend results and handle empty, loading and unavailable-slot states.
